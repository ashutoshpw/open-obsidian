# Native Markdown preview

The Rust UI uses `egui_commonmark = 0.25.0` for native CommonMark rendering. That renderer provides tables, task lists, strikethrough, footnotes, a small set of alert callouts, and a math callback. The native preview renders footnotes and standard `$...$` / `$$...$$` math; task checkboxes, including tasks inside standard callouts, can be toggled. Math uses the pinned `latex-rust = 1.0.2` PNG backend and its embedded STIX Two Math font. Renderer errors and resource-limit rejections show a warning and the original formula text while leaving surrounding Markdown visible. The pinned renderer's mutable API only changes task checkbox markers in the source ([implementation](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark/src/lib.rs#L239-L269)). Legacy `\(...\)` / `\[...\]` delimiters, diagram and plugin fences, unsupported raw HTML and complex highlights remain source-only. The primary note source preview adds a separate vault-context projection for simple single-line plain-text [[target]] and [[target|alias]] links only when every target resolves unambiguously to a local Markdown note with no subpath. The alias is displayed as the link label, and clicking navigates to the resolved note. Unresolved, ambiguous, stale, embedded, subpath, non-Markdown, mixed-formatting, and block-context wiki links remain source-only. An odd backslash run escapes a highlight opener, leaving it literal in the rendered preview; an even run leaves the highlight active and uses the source-only fallback.

`crates/doc` pins `pulldown-cmark = 0.13.4` (MIT) as a direct dependency for a read-only dialect preflight. It is already present in the locked dependency graph through `egui_commonmark`; the direct pin lets document code identify unsupported constructs using parser events without depending on a UI crate. The pin also matches the locked version used by the UI renderer. See the upstream [egui_commonmark 0.25.0 manifest](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark/Cargo.toml), [egui_commonmark renderer parser options](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark_backend/src/pulldown.rs), and [pulldown-cmark 0.13.4 package metadata](https://docs.rs/crate/pulldown-cmark/0.13.4/source/Cargo.toml.orig).

Before the UI invokes the renderer, `analyze_markdown_preview` classifies legacy math delimiters, diagram and plugin fences, raw HTML, wiki links, and highlights. The primary note source preview may override that classification only when wiki links are the sole unsupported construct, the full source is one simple single-line plain-text paragraph, and every link resolves against a stable vault snapshot to a local Markdown note without a subpath. The captured note revision must still match the revision associated with the resolutions; stale results remain source-only and prompt the user to reread the preview. Standard math events use the bounded renderer callback. Other known source-only constructs display the bounded source as monospace text and name those constructs; task checkboxes in that fallback are read-only. Complete, valid UTF-8 note previews of at most 16 KiB receive a SHA-256 revision from the exact bytes read. Toggling a supported task writes the resulting UTF-8 bytes through the vault's journaled write path with that expected revision. An explicit source-edit mode also allows a complete preview to be edited as plain UTF-8 text, including unsupported syntax, with a 16 KiB save limit. Saving either edit uses the captured revision; a stale revision fails closed, preserves the incoming edit in conflict recovery history, and requires reloading the preview. After a successful write, disk reconciliation keeps the preview only while the file still matches the saved revision. Truncated previews have no writable revision and remain read-only. Source drafts preserve untouched BOM, CRLF, and unknown syntax. Markdown and HTML in code blocks remain code; their contents do not trigger the source-only fallback.

This is a partial safe-rendering and editing slice. Plain inline highlights, allowlisted HTML line breaks, and simple resolved wiki links in the primary note preview have bounded read-only projections. Diagram rendering, legacy math delimiters, broader wiki-link contexts and navigation, complex highlights, unsupported HTML, and a general-purpose editor for notes larger than the bounded source draft remain incomplete, so C02.1 remains pending. The fixture `fixtures/markdown-dialects.json` records the intended dialect list, the current Rust preview boundary, golden classification cases, and task/source edit byte-preservation expectations. GitHub Actions on the exact implementation SHA is the only validation gate; no local executable validation is used.

Math preview bounds are shared across note and transclusion previews: at most 32 formula callbacks per egui UI pass, 512 UTF-8 bytes and 48 nested groups per expression, 1024 pixels per raster dimension, 262,144 pixels per raster, 1 MiB of PNG output, and 64 cached formula results with at most 4 MiB of RGBA texture data. PNG dimensions and byte length are checked before decoding. Legacy delimiters and renderer failures remain visibly source-only; very large fallback expressions are shortened in the UI, while the authoritative note bytes are unchanged. Third-party license and font attribution files copied from the exact published crate are under `licenses/latex-rust/` and are linked from `THIRD_PARTY_NOTICES.md`.
