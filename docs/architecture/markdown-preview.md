# Native Markdown preview

The Rust UI uses `egui_commonmark = 0.25.0` for native CommonMark rendering. That renderer provides tables, task lists, strikethrough, footnotes, and a small set of alert callouts. The native preview renders footnotes and allows task checkboxes, including tasks inside standard callouts, to be toggled. The pinned renderer's mutable API only changes task checkbox markers in the source ([implementation](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark/src/lib.rs#L239-L269)); math, diagram and plugin fences, raw HTML, wiki links, and highlights remain source-only until their exact behavior is supported by the migration. An odd backslash run escapes a highlight opener, leaving it literal in the rendered preview; an even run leaves the highlight active and uses the source-only fallback.

`crates/doc` pins `pulldown-cmark = 0.13.4` (MIT) as a direct dependency for a read-only dialect preflight. It is already present in the locked dependency graph through `egui_commonmark`; the direct pin lets document code identify unsupported constructs using parser events without depending on a UI crate. The pin also matches the locked version used by the UI renderer. See the upstream [egui_commonmark 0.25.0 manifest](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark/Cargo.toml), [egui_commonmark renderer parser options](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark_backend/src/pulldown.rs), and [pulldown-cmark 0.13.4 package metadata](https://docs.rs/crate/pulldown-cmark/0.13.4/source/Cargo.toml.orig).

Before the UI invokes the renderer, `analyze_markdown_preview` classifies math, diagram and plugin fences, raw HTML, wiki links, and highlights. If any are present, the bounded source is displayed as monospace text and the UI names those constructs; task checkboxes in that fallback are read-only. Complete, valid UTF-8 note previews of at most 16 KiB receive a SHA-256 revision from the exact bytes read. Toggling a supported task writes the resulting UTF-8 bytes through the vault's journaled write path with that expected revision. An explicit source-edit mode also allows a complete preview to be edited as plain UTF-8 text, including unsupported syntax, with a 16 KiB save limit. Saving either edit uses the captured revision; a stale revision fails closed, preserves the incoming edit in conflict recovery history, and requires reloading the preview. After a successful write, disk reconciliation keeps the preview only while the file still matches the saved revision. Truncated previews have no writable revision and remain read-only. Source drafts preserve untouched BOM, CRLF, and unknown syntax. Markdown and HTML in code blocks remain code; their contents do not trigger the source-only fallback.

This is a partial safe-rendering and editing slice. Wiki-link resolution, highlight rendering, math, diagram rendering, safe HTML projection, and a general-purpose editor for notes larger than the bounded source draft remain incomplete, so C02.1 remains pending. The fixture `fixtures/markdown-dialects.json` records the intended dialect list, the current Rust preview boundary, golden classification cases, and task/source edit byte-preservation expectations. GitHub Actions on the exact implementation SHA is the only validation gate; no local executable validation is used.

The next math-rendering slice evaluates `latex-rust = 1.0.2` as a development-only candidate. Its GitHub CI probe checks PNG output for representative formulas, decodes those bytes through the existing image library, and confirms that TikZ input returns an error. The candidate is not connected to the preview until the three-platform probe passes and its bundled STIX Two Math OFL notice is prepared for distribution.
