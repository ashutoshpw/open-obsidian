# Native Markdown preview

The Rust UI uses `egui_commonmark = 0.25.0` for native CommonMark rendering. That renderer provides tables, task lists, strikethrough, footnotes, and a small set of alert callouts. The native preview renders footnotes and allows task checkboxes to be toggled. The pinned renderer's mutable API only changes task checkbox markers in the source ([implementation](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark/src/lib.rs#L239-L269)); math, diagram and plugin fences, raw HTML, wiki links, and highlights remain source-only until their exact behavior is supported by the migration.

`crates/doc` pins `pulldown-cmark = 0.13.4` (MIT) as a direct dependency for a read-only dialect preflight. It is already present in the locked dependency graph through `egui_commonmark`; the direct pin lets document code identify unsupported constructs using parser events without depending on a UI crate. The pin also matches the locked version used by the UI renderer. See the upstream [egui_commonmark 0.25.0 manifest](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark/Cargo.toml), [egui_commonmark renderer parser options](https://github.com/lampsitter/egui_commonmark/blob/v0.25.0/egui_commonmark_backend/src/pulldown.rs), and [pulldown-cmark 0.13.4 package metadata](https://docs.rs/crate/pulldown-cmark/0.13.4/source/Cargo.toml.orig).

Before the UI invokes the renderer, `analyze_markdown_preview` classifies math, diagram and plugin fences, raw HTML, wiki links, and highlights. If any are present, the bounded source is displayed as monospace text and the UI names those constructs; task checkboxes in that fallback are read-only. Complete, valid UTF-8 note previews of at most 16 KiB receive a SHA-256 revision from the exact bytes read. Toggling a task writes the resulting UTF-8 bytes through the vault's journaled write path with that expected revision. A stale revision fails closed, preserves the incoming edit in conflict recovery history, and requires reloading the preview. After a successful task write, disk reconciliation keeps the preview only while the file still matches the saved revision. Truncated previews have no writable revision and remain read-only. The original source remains visible, and changing a checkbox does not normalize surrounding Markdown. Markdown and HTML in code blocks remain code; their contents do not trigger the source-only fallback.

This is a partial safe-rendering and editing slice. Wiki-link resolution, highlight rendering, math, diagram rendering, safe HTML projection, and freeform Markdown editing remain incomplete, so C02.1 remains pending. The fixture `fixtures/markdown-dialects.json` records the intended dialect list, the current Rust preview boundary, its golden classification cases, and task-toggle byte-preservation expectations. GitHub Actions on the exact implementation SHA is the only validation gate; no local executable validation is used.
