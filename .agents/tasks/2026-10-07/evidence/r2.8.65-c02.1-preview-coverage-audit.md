## Remaining C02.1 scope

The case audit closes the explicit preview-fixture mapping gap, but it does not establish the whole C02.1 criterion. The criterion also covers editing. Existing UI tests separately exercise task-marker editing, task editing inside a standard callout, table-cell source editing, and generic source editing with BOM/CRLF and unsupported syntax. The `rust_preview.rendered_blocks` declaration includes `standard-alert-callouts`, but none of the 21 preview cases directly asserts a standard alert callout's rendered heading and body. The callout task-editing fixture verifies a checkbox mutation, not a dedicated callout render case.

C02.1 therefore remains pending. R2.8.66 will add a standard alert callout to `rust_preview.cases` and verify its visible preview text and unchanged fixture bytes through GitHub Actions. No local executable tests, builds, formatters, linters, or app launches were run for this audit.
